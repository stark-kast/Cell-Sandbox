# Cell-Sandbox

Проект, оригинальная идея которого звучала примерно так: попытка запрограммировать живую клетку, на молекулярном уровне. На самом деле  уже сейчас понятно, что итоговая версия будет далека от того и будет просто симулятором логистики (наподобии Mindastri, Factorio и других).

Сейчас в первой версии реализован костяк того, что я хотел видеть. Три типа объектов: ресурсы, фабрики и машины. Суть проста: машины ищут ресурсы, находя бегут к фабрикам и заполняют их, последние производят. Уже сейчас можно сохдавать производственные цепочки. Наблюдать, как работают десятки и сотни машин и фабрик.

Главное, можно добавлять свои собственные ресурсы, фабрики и машины! Правда пока только через нескомпилированные файлы, по пути: `CellSandbox\objects\registry`.
\* **!**Ошибочка, исходников к v.0.1 у меня нет, так что это доступно только после выхода v.0.2, когда будут исходники.

Разумеется это только первый "снимок", где есть самая база. В это версии нет многих вещей, которые планируются. Нет целой вкладки "Инструменты". Нет настроек. Нет сглаживания! - это кошмар! Мои глаза, да что мои, ваши... Так что пока, это просто демонстрация идеи.

Ну, а то, что планируется, коротко и изброчно:
- Самое больное - бросок объектов, которые вы держите... это сложнее чем вы думаете;
- Переделка внешнего вида боковой панели;
- Отображение скрытых радиусов объектов (поиск, подбор, создание и т.д.);
- Добавить тип объектов "Источники" (со сложной настройкой);
- Добавить тип объектов "Стены" (со сложной настройкой);
- Добавить инструменты и настройки во вкладку "Инструменты";
- Добавить привязку клавишь;
- Добавить сохранения, и внутренний файловый менеджер;
- Добавить сглаживание!;
- Добавить фабрики для фабрик;
- Добавить фабрики для машин;
- множество всякой привсякой мелочи.

Часть из этого уже сделана, но до полноценной v.0.2 недостаёт пару штрихов.
